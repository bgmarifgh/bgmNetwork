# bgmNetwork website

A lightweight static landing page for the bgmNetwork independent pre-launch project.

## Deploy with GitHub Pages

1. Create a public GitHub repository named `bgmNetwork`.
2. Upload the contents of this folder to the repository root (make sure `index.html` is at the root).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main`, folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. The site will normally be at:
   `https://YOUR-GITHUB-USERNAME.github.io/bgmNetwork/`

## Important

This is an informational pre-launch page, not a working bandwidth-sharing service. It does not collect user data or route internet traffic. Do not describe the app as live or claim a network-provider partnership until one exists.
